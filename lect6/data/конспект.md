# Конспект: мережеві протоколи

## Вступ
Цей конспект  містить короткий огляд протоколів прикладного рівня.	
Основна увага — на HTTP,оскільки саме з ним студенти стикаються найчастіше.

#### Навіщо це потрібно
Розуміння протоколу дає змогу читати логи, писати клієнтів і розуміти, що саме саме зламалося.

## HTTP
HTTP - це текстовий протокол запит-відповідь, який працює поверх TCP.
Запит складається з рядка запиту, заголовків і необов'язкового тіла - тіло є, наприклад, у POST.

### Методи
- GET — отримати ресурс
- POST — надіслати дані   
- DELETE — видалити ресурс,якщо сервер це дозволяє

### Коди відповіді
Кодів багато, але запам'ятати варто такі: 200 "ОК", 404 "не знайдено", 500 "помилка сервера".

## TCP і UDP
TCP гарантує доставку й порядок,  UDP — ні.
Через це UDP беруть там, де затримка важливіша за втрати - відео, ігри, DNS.

### Рукостискання
З'єднання починається з трьох кроків: SYN, SYN-ACK, ACK.	
Після цього обидві сторони можуть слати дані.

## Підсумок
Прикладні протоколи будуються поверх транспортних, і саме тому одну й ту саму саму проблему можна бачити на різних рівнях.
